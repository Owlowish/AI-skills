# AI-skills

Bibliothèque de huit skills pour un workflow 3D Blender : références, modélisation, retouche, audit, articulation, pose et préparation FDM.

Les skills et leurs ressources sont dans [workflow](workflow/README.md). Les modèles, références personnelles, environnements et sorties d'impression ne sont pas publiés.

Le refpack minimal comprend huit images, dos détaillé et dos en volumes inclus. Le workflow privilégie les outils sans pilotage d'écran ; tout contrôle d'interface indispensable nécessite un accord explicite préalable dans le chat.

Le dépôt est utilisable comme source Git des skills d'un espace de travail. Le script de liaison Windows conserve une sauvegarde des skills existants et fait pointer .agents/skills vers workflow ; les modifications utilisées localement apparaissent alors directement dans git status.

Les trois nouveaux skills sont des workflows documentés avec contrôles et helpers. Leur présence ne signifie pas qu'un modèle a été riggé, posé ou imprimé ; les validations visuelles et le tranchage se font lors de leur utilisation réelle.
